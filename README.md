## 🎯 Project Vision

As an educator and data science consultant, my goal is to bridge the gap between theoretical physics and interactive, visual learning. This repository houses lightweight, physics-accurate simulations tailored for classroom demonstrations, student labs, and special educational needs. 

The architecture is designed to be highly responsive, utilizing the HTML5 Canvas API and vanilla JavaScript to ensure smooth performance across all devices.

## 🧪 Current Labs

### 1. Faraday's Lab: Electromagnetic Induction
*(Located in `/faradays-lab/`)*

An interactive laboratory modeling Faraday's Law of Induction and Lenz's Law. 

**Features:**
- **Dynamic Physics Engine:** Calculates the rate of change of magnetic flux ($\frac{d\Phi_B}{dt}$) in real-time based on user drag velocity.
- **Visual Feedback:** A realistic galvanometer smoothly maps induced electromotive force (EMF).
- **Lenz's Law Enforcement:** Visual electron flow and accurate needle deflection direction based on magnet polarity (N/S vs S/N) and direction of motion.
- **Interactive Controls:** Polarity flipping and position resetting for continuous experimentation.
